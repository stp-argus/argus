# Code of Conduct

This project follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md),
which is itself adapted from the [Contributor Covenant](https://www.contributor-covenant.org/).

All participants in Argus community spaces (issues, PRs, discussions) are expected to
uphold it. To report a concern, contact the maintainers listed in `MAINTAINERS.md`.
